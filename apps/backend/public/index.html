JESS MOVE API

This host serves the Jess Move API. Every response is JSON under /api. There is nothing to use here directly — the site is at jessmove.com.

Three endpoints answer without any credentials, and say something useful:

  • /api/health — whether the database and the gateway are answering, and which commit is serving this
  • /api/db/status — the schema, and every migration applied to it
  • /api/assurance — the safeguarding and data commitments this platform holds itself to
